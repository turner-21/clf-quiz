# clf-quiz

AWS Certified Cloud Practitioner (CLF-C02) の模擬問題集です。1枚のHTMLファイルで、全4ドメインをカバーする300問を収録しています。

公開ページ: https://turner-21.github.io/clf-quiz/

## 機能

- **通常セッション**: 全300問から15問をランダムに出題します。未回答の問題や、間違えた・自信がなかった問題ほど出やすくなります。
- **弱点だけモード**: 直近の回答が不正解、または「自信がない」を押した問題だけを復習します(最大15問)。
- **その場で解説**: 回答するとすぐに正誤と解説が表示されます。
- **復習まとめ**: セッションの最後に、間違えた問題を分野ごとにまとめて表示します。

回答履歴はブラウザの localStorage に保存され、外部には送信されません。

## ローカルで見る

ビルドは不要です。`index.html` をブラウザで開いてください。

## 注意

学習補助用の模擬問題であり、実際の試験内容や出題形式を保証するものではありません。
